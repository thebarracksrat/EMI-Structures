# Third-party notices

EMI Structures integrates with the public APIs and runtime data provided by the following projects. Their code is not bundled into the EMI Structures JAR.

## EMI

EMI provides the recipe-viewing API and user interface that EMI Structures extends.

Project: https://github.com/emilyploszaj/emi

## NeoForge

NeoForge provides the mod-loading and Minecraft integration APIs used by EMI Structures.

Project: https://github.com/neoforged/NeoForge
